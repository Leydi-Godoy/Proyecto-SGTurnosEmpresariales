================================================================================
¿QUÉ ES UNA MALLA DE TURNOS?
================================================================================

Es la CONFIGURACIÓN que define cómo se distribuyen los turnos:

EJEMPLO: Malla 2x12h
├─ Empresa: Empresa A
├─ Empleados: 60
├─ Cantidad turnos: 2
├─ Horas legales/semana: 42 (Colombia)
├─ Horas legales/mes: 182 (Colombia)
└─ Turnos:
   ├─ Turno Día: 09:00 - 21:00 (12 horas)
   └─ Turno Noche: 21:00 - 09:00 (12 horas)


================================================================================
ESTRUCTURA BASE DE DATOS
================================================================================

Tabla: configuraciones_malla
├─ id (PK)
├─ empresa_id (FK)
├─ nombre (UNIQUE por empresa)
├─ cantidad_empleados
├─ horas_por_semana (default 42)
├─ horas_por_mes (default 182)
├─ dias_laborales_por_semana
├─ cantidad_turnos
├─ tipo_distribucion (equilibrada|personalizada)
├─ descripcion
├─ activo
├─ creado_por, creado_en
└─ actualizado_por, actualizado_en

Tabla: configuraciones_malla_turnos (M2M)
├─ id (PK)
├─ configuracion_id (FK)
├─ plantilla_id (FK)
├─ orden
└─ duracion_horas

================================================================================
ENDPOINTS DISPONIBLES
================================================================================

BASE URL: http://localhost:3001/api/configuraciones-malla

GET /api/configuraciones-malla
├─ Propósito: Listar todas las configuraciones de la empresa
├─ Headers: Authorization: Bearer JWT_TOKEN
├─ Respuesta: { total: number, configuraciones: [] }
└─ Rol: Admin Empresa

POST /api/configuraciones-malla
├─ Propósito: Crear nueva configuración
├─ Headers: Authorization: Bearer JWT_TOKEN
├─ Body: {
│   nombre: string,
│   cantidad_empleados: number,
│   horas_por_semana: number,
│   horas_por_mes: number,
│   dias_laborales_por_semana: number,
│   cantidad_turnos: number,
│   tipo_distribucion: 'equilibrada'|'personalizada',
│   descripcion: string,
│   turnos: [{ plantilla_id, orden, duracion_horas }]
│ }
└─ Rol: Admin Empresa

GET /api/configuraciones-malla/:id
├─ Propósito: Obtener configuración con sus turnos
├─ Headers: Authorization: Bearer JWT_TOKEN
├─ Respuesta: { id, nombre, ..., turnos: [...] }
└─ Rol: Admin Empresa

PUT /api/configuraciones-malla/:id
├─ Propósito: Actualizar configuración
├─ Headers: Authorization: Bearer JWT_TOKEN
├─ Body: (igual a POST)
└─ Rol: Admin Empresa

DELETE /api/configuraciones-malla/:id
├─ Propósito: Eliminar configuración
├─ Headers: Authorization: Bearer JWT_TOKEN
└─ Rol: Admin Empresa
